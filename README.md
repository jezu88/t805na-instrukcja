# Instrukcja obsługi tramwaju Konstal 805Na (opracowanie)

Uproszczona instrukcja obsługi i postępowania przy usterkach tramwaju **Konstal 805Na**,
opracowana na podstawie maszynopisu MPK Łódź *„Opis aparatury elektrycznej wagonu 805Na”*.

> ⚠️ **Materiał szkoleniowy / pomocniczy.** Obowiązujące są przepisy, instrukcje przewoźnika
> oraz polecenia dyspozytora. Dane techniczne odczytane z kopii maszynopisu – mogą zawierać błędy.

## Zawartość (`instrukcja/`)
| Plik | Opis |
|---|---|
| `instrukcja_uproszczona.md` | Uproszczona instrukcja: jak działa wagon, zasady bezpieczeństwa, 8 procedur usterek, ściąga „gdzie co jest”, dane techniczne |
| `notatki_zrodlowe.md` | Wierne notatki z maszynopisu (rozdz. 1–19, s. 1–129) |
| `dane_aplikacji.json` | Dane strukturalne pod przyszłą aplikację mobilną (usterki, lokalizacje aparatów) |

## Stan prac
- ✅ Przepisane rozdz. **1–19** (s. 1–129): pantograf, silniki, styczniki, rozrusznik, przekaźniki,
  hamulce szczękowe i szynowe, stanowisko/pulpit/nastawnik, bezpieczniki, tablice aparatowe,
  przetwornica, akumulatory, przekształtnik 40/24 V, maszyna drzwiowa.
- ⬜ Do uzupełnienia: rozdz. **20–24** (s. 130–150: oświetlenie, dzwonki, grzejniki,
  sterowanie ukrotnione, uszynienie), strony 20–21, 26–27, 29–31, 37; część II (schematy).
